# e-Chama feature map

## Current code structure
- Flutter dashboard, assets, trading, voting, and chat screens
- Firestore schema and Firebase Cloud Functions
- Solidity ChamaCoin token and ChamaDEX sample contracts
- Early test examples

## Prototype functions
- M-Pesa contribution callback
- Loan eligibility multiplier calculations
- AI asset valuation placeholder
- WhatsApp webhook message ingestion
- Simulated ChamaCoin balance minting

## Not production-ready
- M-Pesa callback signature/origin and transaction reconciliation
- Authentication, authorization, tenant isolation, voting integrity
- Asset verification and professional valuation
- Double-entry ledgers, compliant custody and settlement
- Smart-contract audit and compliant trading
- Real WhatsApp group synchronization

Treat feature claims in the source archive as planned capabilities rather than validated production functionality.
