# e-Chama: Blockchain-Powered Chama Management & Investment Platform

A Flutter + Firebase + blockchain platform for Kenyan chamas, with proposed M-Pesa contributions, WhatsApp sync, ChamaCoin tokens, in-house trading, AI asset valuation, loan rules, voting, and investment tracking.

## Tech Stack
- Flutter application
- Firebase Authentication, Firestore, Storage and Cloud Functions
- Solidity contracts for ChamaCoin and ChamaDEX
- Planned integrations: M-Pesa Daraja, WhatsApp Business, AI asset valuation

## Getting started
```bash
flutter pub get
flutter run
cd functions && npm install
```

Configure Firebase and server-side environment variables before deploying.

## Security and legal review
The code is an initial implementation, not an audited production financial system. Contracts, payments, custody, authorization, KYC/AML and applicable Kenyan regulatory obligations require validation prior to live use.
